## drag-share v0.1.0 · 首个发布版本

macOS 菜单栏中的 SMB 共享助手：共享文件夹、复制局域网地址，用完关闭服务，目录配置继续保留。

### 本次功能

- 菜单栏常驻与 320×440 浮动面板，支持明暗主题。
- 一键启停 macOS 内置 SMB，通过系统原生管理员授权执行写操作。
- 选择或拖入文件夹添加共享，拦截重复目录与普通文件。
- 查看共享权限属性、复制本机或目录链接，支持中文、空格和引号。
- 二次确认移除共享记录，不删除目录内容。
- Control + Option + S 快捷键、可选登录自启、Finder 定位与系统设置入口。
- 本地日志，无遥测、不存储密码、不扫描共享目录内容。

### 下载与安装

| 附件 | 用途 |
| --- | --- |
| `drag-share-0.1.0-macos-arm64.dmg` | 推荐安装包；打开后将应用拖入「应用程序」 |
| `drag-share-0.1.0-macos-arm64.app.zip` | 应用 ZIP；解压后将应用移入「应用程序」 |
| `SHA256SUMS.txt` | 两个下载文件的 SHA-256 校验值 |

**系统要求：macOS 13+，Apple Silicon / arm64。当前不提供 Intel、Windows 或 Linux 安装包。** GitHub 自动生成的 Source code 附件为源码，不是可直接运行的软件。

应用使用本地 ad-hoc 签名，尚未经过 Apple Developer ID 签名及公证。首次打开如被系统拦截，请在确认下载来源后，按「系统设置 → 隐私与安全性」中的系统提示允许打开，无需关闭 Gatekeeper。

首次使用请在系统共享设置中确认 SMB 及所需账户已启用。设备需要位于可互通的局域网内。**退出工具不会自动停止系统 SMB；如需停止对外共享，请先点击「关闭共享」。**

## English

The first release of **drag-share**, a menu-bar companion for macOS built-in SMB sharing.

Start or stop SMB while preserving configured folders; add folders through the native picker or panel drop target; copy host and folder links; remove shares without deleting local files. Includes a global shortcut, optional login startup, Finder integration and system appearance support.

**Download:** macOS 13+ on **Apple Silicon / arm64** only. Choose the DMG installer or application ZIP; `SHA256SUMS.txt` contains their integrity hashes. GitHub's Source code archives require building from source. The UI is currently Simplified Chinese.

The app is ad-hoc signed, without Developer ID signing or Apple notarization. If macOS blocks the first launch, verify the source and follow its instructions in **System Settings → Privacy & Security**. Do not disable Gatekeeper.

Configure SMB and allowed accounts in macOS sharing settings before connecting. Devices must be on a reachable local network. **Quitting the app does not stop system SMB.**

39 local automated tests and macOS CI passed. Real authorization dialogs, device transfers, login startup, multi-monitor behavior and long-running resource targets remain manual acceptance items. No system sharing configuration was changed during automated verification.
