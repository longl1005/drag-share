# v0.2.0 — Windows 首发准备

选择 0.2.0：新增完整 Windows 平台后端和安装包，作为独立功能里程碑；既有 v0.1.2 下载仍保留。此版本未发布，未 push，不创建 GitHub Release。

- Windows 10/11 x64：任务栏通知区域托盘、面板、Ctrl+Alt+S、目录选择与拖入、Explorer 定位、共享设置、登录启动。
- PowerShell 5.1 / SmbShare：状态、共享列表与 ACL 属性、增删、Server 服务启停、IPv4 / 计算机名地址。
- 每次写操作使用 UAC `Start-Process -Verb RunAs`，脚本通过 UTF-16LE EncodedCommand 传递；无密码存储、无临时提权脚本文件。执行账户在提权前读取，支持使用另一管理员账户授权。
- 新共享仅授予应用启动账户 Change 权限；NTFS、系统账户、网络发现、防火墙和访客策略由用户在 Windows 设置中管理。
- 系统管理共享不可删除，关闭服务不删除配置，不强制停止依赖服务。
- Windows 保持唤醒使用 SetThreadExecutionState，允许显示器休眠，停用或退出时释放。ZIP 需要已安装 WebView2 Runtime；NSIS 使用 Tauri 默认 WebView2 引导安装策略。安装包未签名。
- macOS arm64 / Intel 保留既有 runner、app / DMG 构建、签名检查和包名。

## 构建和交付

在 GitHub Actions 的 Verify drag-share 手动 Run workflow，或提交至远端后由 push / PR 触发（本次不 push）。Windows job 会执行前端检查、Rust 单元测试、fmt / clippy 和 `scripts/build-windows.ps1`。测试包含真实 Windows PowerShell 执行封装和 mock cmdlet fixture，不触碰系统 SMB 配置、不请求 UAC。

Windows artifact `windows-x64`：

- `drag-share-0.2.0-windows-x64-setup.exe`（NSIS，当前用户安装）
- `drag-share-0.2.0-windows-x64.zip`（单 exe，依赖 WebView2）
- `SHA256SUMS.txt`

`release-assets` job 汇总 Windows 与 macOS 六个包，重新生成统一 SHA-256。CI 无 Release 写权限、无发布步骤。Windows 本地构建：`npm ci` 后执行 `./scripts/build-windows.ps1`。当前脚本固定标准 target 目录，不支持自定义 CARGO_TARGET_DIR。

## 发布前人工验收

1. Windows 10 / 11 x64：全新安装、ZIP、首次 WebView2 安装、卸载、普通账户启动、任务栏折叠区域图标。
2. UAC 同意、取消、另一管理员凭据、无管理员权限；中文系统和英文系统。等待授权超时后刷新确认最终系统状态，避免将超时视为回滚（提升后的进程可能仍完成操作）。
3. 开关 Server 服务、依赖服务阻止停止、重启后的启动类型、已有共享配置保留；外部修改后刷新。
4. 中文、空格、单引号、美元符目录；重复路径、大小写别名、已删除目录、非法共享名称、UNC 和管理共享保护。
5. 两台设备真实连接、读写、账户与 NTFS 权限、专用网络防火墙、断网与主机名回退。应用不会自动开放入站端口。
6. 高 DPI、多屏、任务栏顶部/底部/侧面、面板失焦、拖入、Esc、快捷键冲突、Explorer、登录启动与单实例。
7. macOS arm64 / Intel CI 和真机回归；通过后再手工签名、整理 Release 附件并发布。

实现依据：[Microsoft SmbShare](https://learn.microsoft.com/en-us/powershell/module/smbshare/) 与 [New-SmbShare](https://learn.microsoft.com/en-us/powershell/module/smbshare/new-smbshare)。
