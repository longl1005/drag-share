## v0.1.1 · 修复没有共享目录时无法添加的问题

### 修复

删除最后一个共享目录后，macOS 的 `sharing -l -f json` 仍可能返回纯文本 `No share point records.`，而不是 JSON 空对象。v0.1.0 将它误判为解析失败，导致界面显示「无法解析系统共享目录」并禁用添加入口。

本版本将该成功响应正确识别为空列表，恢复「还没有共享目录」引导。服务开启后可正常选择或拖入文件夹。真实的查询失败仍会报错，不会被当作空列表隐藏。

### 安装

下载 `drag-share-0.1.1-macos-arm64.dmg`，退出旧版共享助手，将新版应用拖入「应用程序」并替换，然后重新打开。也可使用应用 ZIP。需要 macOS 13+ 和 Apple Silicon；未提供 Intel、Windows 或 Linux 构建。

**服务关闭时，仍需先点击「开启共享」再添加目录。** 这是既定行为，不会因本次修复而更改。

附件包括 DMG、应用 ZIP 和 `SHA256SUMS.txt`。应用使用 ad-hoc 签名，未经过 Apple 公证。

### 验证

新增两个回归测试，覆盖真实空列表输出、前后空白和真实查询错误。Rust 19 项、前端 11 项、浏览器 11 项测试通过。继续采用无人值守验证，不自动启停 SMB、添加目录或更改登录项。

---

## English

Fixes a v0.1.0 bug where removing the last share caused a parsing error and prevented adding a new folder. macOS can return the plain-text success response `No share point records.` even when JSON output is requested. Both parsers now recognize this as an empty list while preserving actual query errors.

Quit the old app, replace it with v0.1.1 and relaunch. **Start the sharing service before adding folders.** Requires macOS 13+ on Apple Silicon. The app is ad-hoc signed, without Apple notarization.

Regression coverage: 19 Rust, 11 frontend and 11 browser tests. Unattended verification does not mutate system SMB configuration.
